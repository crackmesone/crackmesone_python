# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in crackmes.one, please report it to us by emailing:

**crackmesone@gmail.com**

Please include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

## Bounty Program

We do not currently offer a bug bounty program. However, we greatly appreciate your efforts to help make crackmes.one more secure for everyone.

## Response

We will review your report and respond as soon as possible. Please allow us reasonable time to address the issue before any public disclosure.
